# My Favorite Series: Avatar: The Last Airbender

**Avatar: The Last Airbender** is an animated fantasy-adventure series about a boy named Aang, who must master the four elements and bring balance to the world.

## Why I Like It
- Great story about friendship, family and courage
- Every character grows and changes over time
- Beautiful world inspired by different cultures
- Funny moments that balance the serious ones

## Quick Facts
| Detail | Info |
|--------|------|
| Genre | Animation, Fantasy, Adventure |
| Seasons | 3 (Water, Earth, Fire) |
| Main Character | Aang |

## My Top 3 Characters
1. Aang
2. Zuko
3. Uncle Iroh

> My favorite part is how even the villains learn and change.
